This code was made using Pygame. 
How to play: click right to move the basket right and left to move the basket left.
If you catch the ball you earn 1 point and if the ball falls then you lose a life. You have three lives, the game end when you lose all your lives.
Concepts: Pygame:a library that make it easy to make games on python, While loop: this loop runs 60 times per second also handling input, updating the game and drawing the screen,
Rectangle: the basket and ball are rectangle set at different positions and different size, Collision detection: check if two rectangles are touching,
Random numbers: sets a new position for the ball every time, Events and keys: Pygame detects key presses and window closes, Frame rate: keeps the game running at 60 frames per second.
